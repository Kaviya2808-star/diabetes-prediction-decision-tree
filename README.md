Diabetes Prediction using Decision Tree

Project Overview

This project predicts whether a patient has diabetes using the Decision Tree Classification algorithm. The model is trained on the Pima Indians Diabetes Dataset and evaluated using machine learning performance metrics.

Objective

The objective of this project is to build a machine learning model that predicts diabetes based on patient medical information.

Dataset

Dataset Name: Pima Indians Diabetes Dataset

Input Features:

- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age

Target Variable:

- Outcome (0 = Non-Diabetic, 1 = Diabetic)

Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

Machine Learning Algorithm

Decision Tree Classifier

Project Steps

1. Import the required libraries.
2. Load the dataset.
3. Explore and preprocess the data.
4. Split the dataset into training and testing sets.
5. Train the Decision Tree model.
6. Make predictions.
7. Evaluate the model using Accuracy Score, Confusion Matrix, and Classification Report.

Results

Model: Decision Tree Classifier

Accuracy: 74.68%

Conclusion

The Decision Tree model successfully predicts diabetes with an accuracy of 74.68%. The model provides satisfactory performance and can be improved further by using advanced machine learning algorithms and parameter tuning.

Future Scope

- Improve accuracy using Random Forest or XGBoost.
- Perform hyperparameter tuning.
- Use a larger dataset for training.
- Deploy the model as a web application.
